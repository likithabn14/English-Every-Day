# 📚 English Every Day

**English Every Day** is a modern vocabulary learning web application built using **Python** and **Streamlit**. It helps users improve their English vocabulary through daily word practice, real-time dictionary definitions, pronunciation audio, interactive quizzes, and personalized learning history.

Designed with a clean interface and modular architecture, the application provides an engaging learning experience while demonstrating practical software development skills such as API integration, state management, and responsive UI design.

---

## ✨ Features

* 📖 Learn a new English word every day
* 🌐 Real-time definitions using the Free Dictionary API
* 🔊 Audio pronunciation with Google Text-to-Speech (gTTS)
* 📝 Parts of speech and example sentences
* 🎯 Interactive multiple-choice vocabulary quiz
* 📚 Save difficult words to your personal learning history
* 🔄 Randomized vocabulary engine with 100 curated words
* ⚡ Fast and responsive Streamlit interface
* 📱 Fully responsive web application
* ☁️ Easy deployment on Streamlit Community Cloud

## 🎮 How It Works

1. Open the application.
2. Discover a new English vocabulary word.
3. Read its definition and example.
4. Listen to its pronunciation.
5. Take the vocabulary quiz.
6. Save difficult words for later revision.
7. Continue learning every day.
